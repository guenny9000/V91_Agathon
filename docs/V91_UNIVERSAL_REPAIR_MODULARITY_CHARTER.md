# V91 Universal Repair & Modularity Charter (V91-UAPO 2.1)

Date: 2026-11-05
Status: verbindliches V91-Prüfkriterium (Reality-First)

## Grunddirektive

**KOMPATIBILITÄT = REPARATURFÄHIGKEIT = LANGLEBIGKEIT**

Jedes technische Konzept, jede Beschaffung und jede Architekturentscheidung im
V91-Umfeld muss diese Gleichung erfüllen. Künstliche Komplexität ist ein
Designfehler, kein Feature.

## Direktiven

1. Austauschbare Komponenten statt Wegwerfgeräte.
2. Genormte Akkus und Batterien (z. B. leicht zugängliche BIOS-Knopfzellen in
   genormtem Format; keine fest verbauten, unzugänglichen Zellen).
3. Zugängliche, standardisierte Anschlüsse (USB-C, genormte Steckverbinder).
4. Wiederverwendung statt unnötiger Neuanschaffung.
5. Offene Standards statt künstlicher Herstellerabhängigkeit (Vendor Lock-in).
6. Reparatur ohne Spezialwerkzeug; Demontage ohne Zerstörung anderer Teile.
7. Sicherheitsupdates auch für langlebige Geräte; keine Sicherheitslücke durch
   Langlebigkeit.

## Prüfkriterien (Kennzahlen)

| Kennzahl                 | Ziel                |
| ------------------------ | ------------------- |
| Reparierbarkeit          | Maximieren          |
| Ersatzteilverfügbarkeit  | Langfristig sichern |
| Herstellerabhängigkeit   | Minimieren          |
| Elektroschrott           | Reduzieren          |
| Energieverbrauch         | Minimieren          |
| Rückwärtskompatibilität  | Erhalten            |
| Datensicherheit          | Nicht verschlechtern|

## Langlebigkeits-Fragen (jedes neue Konzept muss sie bestehen)

1. Kann man es reparieren?
2. Kann man Einzelteile austauschen?
3. Gibt es offene Standards?
4. Kann es mit älteren Komponenten weiterarbeiten?
5. Werden Energie und Rohstoffe eingespart?
6. Entsteht durch die Verbesserung keine neue Sicherheitslücke?

## Grenzen (ehrlich)

- Dieses Dokument ist ein Prüfkriterium, kein Messergebnis. Konkrete Geräte
  oder Infrastruktur gelten erst dann als "reparaturfähig", wenn das vor Ort
  geprüft und dokumentiert wurde (CLAIM = EVIDENCE).
- Ein "V91 Universal Repair Standard" für Computer, Smartphones, Haushaltsgeräte
  und Infrastruktur wäre ein Folgeprojekt und erfordert eigene Validierung.

## Leitsatz

Nicht ständig neu bauen. Das Vorhandene intelligenter, langlebig und besser machen.
Keine künstliche Obsoleszenz. Keine unnötige Ressourcenverschwendung.
